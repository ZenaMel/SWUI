### 8. `docs/runtime-overview.md`

Architecture flow:
```
SwuiLoader (PreDefault) → FSwuiRuntime::StartupModule
  └─ CefInitialize with SwuiManager (CefApp)
  └─ Sets process path, cache, off-screen rendering

USwui::BeginPlay
  └─ USwuiSubsystem::SetBindingSources  (scans world for matching actors)
  └─ USwuiSubsystem::InitRenderer
       └─ USwuiView::Init
            └─ new RenderHandler → new BrowserClient → CefBrowserHost::CreateBrowserSync
            └─ SetWindowlessFrameRate
            └─ Creates UTexture2D (PF_B8G8R8A8)
       └─ Creates UUserWidget with UCanvasPanel + UImage
       └─ AddToViewport

RenderHandler::OnPaint (CEF renderer thread)
  └─ USwuiView::OnPaint
       └─ Band or Per-Rect upload strategy
       └─ ENQUEUE_RENDER_COMMAND → RHIUpdateTexture2D

USwuiSubsystem::Tick (every engine frame, FTickableGameObject)
  └─ Throttled by CEF windowless frame rate (TickAccumulator)
  └─ Pushes runtime info + observed state → ExecuteJavaScript
  └─ State written into window.__SWUI__.state + _notify()

CEF sub-process: SwuiBrowserProcess.exe (from ThirdParty/cef/)
```

Key settings class: `USwuiSettings` (Project Settings > Plugins > SimpleWebUI) with `bDisablePlugin`, `CefOffscreenFrameRate`, `DefaultViewFrameRate`, `MaxBandOvercopyRatio`, `MaxPerRectUploads`, `bVerbosePaintLog`, `bNoTextureUpload`.

### 9. `docs/interop.md` — Unreal ↔ JavaScript Interop
- State push is unidirectional (Unreal → JS), via `ExecuteJavaScript`
- `window.__SWUI__` is the shared state object
- `__SWUI__.state` holds all key-value pairs
- `__SWUI__._notify(key, value)` is patched by `swui.ts` to fire subscribers
- JS client import: `import Swui from '@simplewebui/client'`
- API: `Swui.on(key, fn)`, `Swui.get(key)`, `Swui.getAll()`
- Blueprint → CEF: `ExecuteJavaScript` on `USwuiView`
- URI resolution: `http://`, `https://`, `localhost`, `file:///` pass through; bare paths resolve under `Content/` with `.html` implicit
- CEF remote debugging on port 7777
- Runtime info (fps, dt, cefFps, width, height) pushed every tick via `swui:tick` CustomEvent
- Unsupported types: structs, arrays, objects, enums (only `number`, `boolean`, `string`)

### 13. `docs/dirty-field-tracking.md`

**Critical finding from code analysis: There is NO dirty field comparison implemented.** Every tick serializes ALL observed properties unconditionally. The actual behavior based on `SwuiSubsystem::Tick`:

- **Registration**: Properties are registered via `ObserveProperty()` → `FSwuiObservedProperty` entries stored in `ObservedProperties` array. Each entry holds: `TWeakObjectPtr<UObject> Source`, `FString NamespacedKey`, `FName PropertyName`, `FProperty* CachedProp`.
- **Tracking**: No per-field dirty tracking. Every tick loops `ObservedProperties` and serializes every property via `Swui_SerializeProperty()`.
- **Change detection**: None implemented — values are always pushed.
- **Skip unchanged**: Not implemented. Every property is serialized and injected every tick.
- **Serialization**: `Swui_SerializeProperty()` handles `float`, `double`, `int32`, `int64`, `uint8`, `bool`, `FString`, `FName`, `FText`.
- **Update to JS**: Injected as JavaScript: `s.state['key']=value;if(s._notify)s._notify('key',value);`
- **JS receipt**: `swui.ts` patches `_notify` to call subscriber callbacks.
- **Events**: `OnObservedDelegateFired()` is a trampoline — fires all live delegates with empty `CustomEvent` detail. Rich payload dispatch is not yet implemented (delegate payload fields are cached but unused in dispatch).
- **Throttling**: `TickAccumulator` in `USwuiSubsystem::Tick` throttles pushes to match CEF windowless frame rate. Not per-field batching/coalescing.
- **Reducing unnecessary work**: None for state serialization. Paint/upload optimization is separate (see performance page).
- **Limitations**: (1) No change comparison — every property serialized every tick. (2) Event dispatch is a broadcast ping with no payload. (3) Only simple types supported. (4) `FString` values are serialized with single-quote wrapping (may break on strings containing `'`).
- **Relevant types/functions**: `FSwuiObservedProperty`, `FSwuiObservedDelegate`, `Swui_SerializeProperty()`, `Swui_GetTSType()`, `USwuiSubsystem::Tick`, `ObserveProperty()`, `ObserveDelegate()`, `OnObservedDelegateFired()`, `ResolveNamespace()`, `K2_Observe()`, `K2_ObserveEvent()`.

### 14. `docs/performance-paint-upload.md`

Based on `USwuiView::OnPaint()` and `RenderHandler::OnPaint()`:

- **CEF offscreen rendering**: CEF renders to a pixel buffer in `PF_B8G8R8A8` format via `CefRenderHandler::OnPaint`.
- **OnPaint handling**: `RenderHandler::OnPaint` receives the full buffer + dirty rects. Converts to `FUpdateTextureRegion2D` array, forwards to `USwuiView::OnPaint`.
- **Dirty rect handling**: Rect coords clamped to texture bounds, zero-area rects skipped.
- **Two upload strategies**:
  1. **Band path** (default when per-rect criteria not met): Single memcpy of full-width band `[MinRow..MaxRow]`, then one `RHIUpdateTexture2D` per rect (sharing the same SrcData buffer, with SrcY rebased to band-relative). Upload pixel count = BandArea = width * bandRows.
  2. **Per-rect tight-pack path**: Each rect gets its own tightly-packed pixel buffer (no wasted columns). Each rect uploaded independently via `RHIUpdateTexture2D`. Upload pixel count = sum of rect areas.
- **Strategy decision** (`bUsePerRect`): Use per-rect when:
  - `BandArea > DirtyArea * MaxMergeOvercopyRatio` (band is too wasteful), AND
  - `ValidRectCount <= MaxPerRectUploads` (not too many small calls)
- **`CVarSwuiMaxMergeOvercopyRatio`** (`swui.paint.MaxMergeOvercopyRatio`, default 1.25): Band-merge overcopy guard threshold. Lower = prefer per-rect more aggressively.
- **`CVarSwuiMaxPerRectUploads`** (`swui.paint.MaxPerRectUploads`, default 32): Maximum per-rect RHI calls before falling back to band.
- **`CVarSwuiNoTextureUpload`** (`swui.prof.NoTextureUpload`, default 0): Skip `RHIUpdateTexture2D` to isolate CPU-side cost.
- **`CVarSwuiVerbosePaint`** (`swui.prof.VerbosePaint`, default 0): Log per-paint strategy, areas, ratio, memcpy time.
- **Diagnostic counters** (one-second aggregate log):
  - `paints/s`, `dirtyRects/s`, `dirtyPx/s`, `uploadedPx/s`
  - `bandRatio` = uploadedPx / dirtyPx (overcopy ratio)
  - `memcpyAvgMs`, `memcpyMaxMs`
  - `largestDirtyRect`
  - Texture dimensions
- **Why sparse dirty rects should not be merged into full-width bands**: If dirty rects are scattered vertically, the row band covers the full width for every row between the first and last dirty pixel, drastically overcopying. The `MaxMergeOvercopyRatio` threshold guards against this.
- **High-refresh HUD support**: `WindowlessFrameRate` defaults to 300 (uncapped), adjustable via `DefaultViewFrameRate` setting. No hard 60 FPS cap. Frame rate selection priority: `DefaultViewFrameRate > 0` → use it, else `GEngine->GetMaxFPS() > 0` → follow engine cap, else 300.
- **Relevant types/functions**: `USwuiView::OnPaint`, `RenderHandler::OnPaint`, `ISwuiRenderTarget::OnPaint`, `FSwuiRectUpload`, `FSwuiPerRectUploadData`, `FUpdateTextureRegionsData`, `USwuiSettings::MaxBandOvercopyRatio`, `USwuiSettings::MaxPerRectUploads`, `CVarSwuiMaxMergeOvercopyRatio`, `CVarSwuiMaxPerRectUploads`, `CVarSwuiNoTextureUpload`, `CVarSwuiVerbosePaint`.

### 15. `docs/best-practices.md`
- Keep observed properties to primitive types only
- Use `ObserveSource` instead of individual `SWUI Observe` nodes for the common case
- Call `Unobserve` on `OnUnPossess` / before destroying observed actors
- Set appropriate `DefaultViewFrameRate` to match monitor refresh rate
- `CefOffscreenFrameRate` must be >= `DefaultViewFrameRate`
- Place HTML under `Content/UI/`
- Regenerate TS bindings after changing checked properties
- Use `bIsHUD = true` for viewport-matching surfaces
- Structure JS code to subscribe in `DOMContentLoaded`

### 16. `docs/troubleshooting.md`
- Plugin not working: Check Project Settings > Plugins > SimpleWebUI > `bDisablePlugin`
- CEF not loading: Check `SwuiBrowserProcess.exe` exists in `ThirdParty/cef/Win/shipping/`
- Black screen: Verify URI path, check CEF remote debugging at `http://localhost:7777`
- State not syncing: Verify properties are BlueprintReadWrite/ReadOnly and checked in bindings
- TS generation fails: Check Output Log for details
- Runtime disable: `USwuiSubsystem::DisablePlugin()` or `USwuiSubsystem::IsPluginDisabled()`
- Paint perf issues: Tune `MaxBandOvercopyRatio`, `MaxPerRectUploads`, profile with `swui.prof.VerbosePaint 1`
- Known limitation: FPS log shows avg FPS from engine, not actual CEF render rate

### 17. `docs/development-workflow.md`
- Dev setup: Clone repo, add to UE project's `Plugins/` folder
- Build: Generate project files, compile
- Test with `bDisablePlugin = false`, check Output Log for SWUI STATUS
- Use `swui.prof.VerbosePaint 1` for paint diagnostics
- Use `swui.prof.NoTextureUpload 1` to isolate CPU upload cost
- Remote debugging: `http://localhost:7777` for CEF DevTools
- For C++ changes touching the client lib, rebuild `SwuiClientLib` with Vite
