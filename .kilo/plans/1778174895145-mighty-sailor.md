# Clean Slate: Delete Old Stringy/Glue API

## Objective

Remove every file and symbol from the existing "SWUI" layer that embodies the raw-string, manual-JSON, "ExecuteJS" pattern. Keep only the low-level CEF integration (the backend) and the module shell. Then write new placeholder headers for the reflection-driven GameWebUI API.

---

## What Stays (the CEF backend)

These files form the backend adapter layer. They are **kept** (possibly with minor cleanup):

| File | Reason to keep |
|---|---|
| `Source/SwuiRuntime/Public/SwuiManager.h` | CEF app lifecycle, command-line args, message loop |
| `Source/SwuiRuntime/Private/SwuiManager.cpp` | CEF settings init, command-line switches |
| `Source/SwuiRuntime/Public/RenderHandler.h` | CEF render handler + BrowserClient (CEF client composition) |
| `Source/SwuiRuntime/Private/RenderHandler.cpp` | OnPaint, process messages, download, lifecycle |
| `Source/SwuiRuntime/Private/SwuiRuntime.cpp` | Module startup (CEF init), shutdown |
| `Source/SwuiLoader/Public/ISwuiLoader.h` | Module interface (DLL load helper) |
| `Source/SwuiLoader/Private/SwuiLoader.cpp` | Module implementation (DLL directory push) |
| `Source/SwuiRuntime/SwuiRuntime.Build.cs` | Build rules (CEF libs, DLLs, deps) |
| `SimpleWebUI.uplugin` | Plugin descriptor |
| `builder/` | CEF build scripts (keep as-is) |

## What Gets Deleted (the old stringy API)

| File | What it represents (why deleted) |
|---|---|
| `Source/SwuiRuntime/Public/SwuiEye.h` | Raw browser wrapper with `ExecuteJS`, `LoadURL`, `TriggerLeftClick`, etc. The old "eye" pattern. Replaced by `USwuiView`. |
| `Source/SwuiRuntime/Private/SwuiEye.cpp` | Implementation of the above (782 lines). All raw CEF interop, texture management, event loop. |
| `Source/SwuiRuntime/Public/SwuiJsonObj.h` | Manual JSON parsing with `GetStringValue("key")` / `SetStringValue(...)`. Raw string key access. Replaced by typed payload/schema system. |
| `Source/SwuiRuntime/Public/SwuiBlueprintFunctionLibrary.h` | Factory functions: `NewSwuiEye`, `NewSwuiJsonObj`, `ParseJSON`, `JSONToString`. Old BP factories. |
| `Source/SwuiRuntime/Private/SwuiBlueprintFunctionLibrary.cpp` | Implementation of the above. |
| `Docs/.d` (and `Docs/` directory) | Old docs not relevant to new approach. |
| `README.md` | Full rewrite to match GameWebUI description. |

## Files That Get Cleaned Up (not deleted, but surgically stripped)

### `Source/SwuiRuntime/Public/SwuiTypes.h`

Remove:
- `FTickEventLoopData` — was used by `USwuiEye`'s tick pattern
- `FSwuiTextureParams` — dead struct, was used by old texture flow
- `FUpdateTextureRegionsData` — was used directly in `USwuiEye::TextureUpdate`
- `ESwuiSpecialKeys` enum — raw key-code enum, part of old input forwarding API
- `FSwuiEyeSettings` — old settings struct for `USwuiEye`
- `FScriptEvent` delegate — this is THE canonical "raw string event" delegate: `(FString EventName, FString EventMessage)`
- `FLogEvent` delegate — console log redirect (can stay or move to backend adapter)
- `FDownloadCompleteSignature`, `FDownloadUpdatedSignature` — download delegates only used by USwuiEye

Keep:
- Core includes
- The `DECLARE_LOG_CATEGORY_EXTERN` if needed

Eventually this file can be deleted entirely once the new types settle, but for the clean-slate step we can gut it.

### `RenderHandler.h` / `RenderHandler.cpp`

Keep the CEF plumbing. But remove:
- `USwuiEye* ParentUI` from `RenderHandler` (replace with a backend interface callback)
- `BrowserClient::SetEventEmitter`, `SetLogEmitter` — remove raw `FScriptEvent`/`FLogEvent` pointers
- `OnProcessMessageReceived` — the raw `js_event` string matching path
- Remove the `#include "SwuiEye.h"` from `RenderHandler.cpp`

**Or**: keep `RenderHandler` and `BrowserClient` as-is for now, since they compile independently of `USwuiEye` except for the `ParentUI` reference. We can address this in a follow-up pass when the new backend adapter is written.

## New Files to Create (placeholder headers)

These establish the new reflection-driven API shape. They will be fleshed out in subsequent work, but the clean-slate step adds them as empty/stub headers so the project compiles and the intent is clear.

### `Source/SwuiRuntime/Public/SwuiBridge.h`

```cpp
UCLASS(ClassGroup=Swui, Blueprintable)
class SWUIRUNTIME_API USwuiBridge : public UActorComponent
{
    GENERATED_BODY()
public:
    UFUNCTION(BlueprintCallable, Category="SwuiRuntime")
    void LoadBindings(USwuiBindingAsset* BindingAsset);

    UFUNCTION(BlueprintCallable, Category="SwuiRuntime")
    void RegisterSource(FName SourceName, UObject* SourceObject);

    UFUNCTION(BlueprintCallable, Category="SwuiRuntime")
    void ForceSync();
};
```

### `Source/SwuiRuntime/Public/SwuiView.h`

```cpp
UCLASS(ClassGroup=Swui, Blueprintable)
class SWUIRUNTIME_API USwuiView : public UObject
{
    GENERATED_BODY()
public:
    UFUNCTION(BlueprintCallable, Category="SwuiRuntime")
    void Init();

    UFUNCTION(BlueprintCallable, Category="SwuiRuntime")
    void LoadURL(const FString& URL);

    UFUNCTION(BlueprintCallable, Category="SwuiRuntime")
    void ExecuteJavaScript(const FString& Script);
};
```

### `Source/SwuiRuntime/Public/SwuiBindingAsset.h`

```cpp
UCLASS(ClassGroup=Swui, BlueprintType)
class SWUIRUNTIME_API USwuiBindingAsset : public UDataAsset
{
    GENERATED_BODY()
};
```

### `Source/SwuiRuntime/Public/SwuiTypes.h` (rewritten)

Gut the old structs, keep only:
- `DECLARE_LOG_CATEGORY_EXTERN(LogSwuiRuntime, Log, All);`
- New forward declarations if needed

### `README.md` (rewritten)

Replace with the GameWebUI elevator pitch from the engineering brief.
